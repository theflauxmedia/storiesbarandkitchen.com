# Stories Bar & Kitchen

Premium marketing site for [storiesbarandkitchen.com](https://storiesbarandkitchen.com) — a Bengaluru rooftop bar & kitchen chain.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Framer Motion
- Static export (`output: 'export'`) → `/out`

## Commands

```bash
# Local development
npm run dev

# Production static build (writes to /out)
npm run build
```

Open [http://localhost:3000](http://localhost:3000) after `npm run dev`.

## Deploy

Upload the contents of `/out` to any static host (Netlify, Cloudflare Pages, S3, nginx, etc.).
