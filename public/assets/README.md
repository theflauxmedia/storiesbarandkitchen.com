# Image assets convention

Drop optimised photography here:

```
public/assets/<outlet-slug>/<category>/<file>.webp
public/assets/_shared/<category>/<file>.webp
```

**Outlet slugs** (must match exactly): `hsr-layout`, `nagarbhavi`, `rajajinagar`

**Shared** (`_shared`): brand-wide shots (e.g. plated food) that appear on every location’s gallery and when any location filter is selected.

**Category** becomes a filter tag automatically. Suggested names from the content plan: `ambience`, `food`, `drinks`, `events`, `live-performances`, `celebrations`, `guest-moments`, `corporate-parties`, `family-gatherings`, `dj-nights`.

Formats supported: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.

Prefer WebP under ~200KB, max width ~1400–1600px for gallery tiles; hero/OG can be wider.

Raw camera dumps do **not** belong here — keep them outside the repo, curate, then drop only optimised files.
